## 1. Linux・ターミナル操作

```bash

```


#### `pwd`

現在いるディレクトリのパスを確認する。

```bash

```

## 3. ファイル検索

### `find`

ファイルやディレクトリを検索する。

`*` を使った検索について確認した。

```bash
find . -name "*a*"
```

### `*` の意味

`*` は「0文字以上の任意の文字列」を表す。

そのため、

```text
*a*
```

は、

```text
a
abc
cat
data
```

など、名前のどこかに `a` が含まれているものにマッチする。

「0文字以上」なので、`a` の前後に何もなくてもマッチする。

## 5. `printf` とリダイレクト

以下のコマンドを実行した。

```bash
printf 'alpha\nbeta\n' > a.txt
```

### それぞれの意味

- `printf`
  - 文字列を出力する
- `\n`
  - 改行を表す
- `>`
  - 標準出力をファイルへリダイレクトする

結果として `a.txt` に、

```text
alpha
beta
```

が書き込まれる。

さらに、

```bash
printf 'gamma\n' > b.txt
```

を実行し、新しいファイルへ文字列を書き出す動きも確認した。
